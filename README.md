# Homebase Filesync

Keeps a folder on your computer in sync with your [Homebase](https://homebase.id) drive, on
Windows, macOS and Linux: a small tray app, a per-user daemon (`hbsyncd`) that does the
syncing, and a command line (`hbsync`). Every file is encrypted before it leaves your computer.

Developer notes are in [CLAUDE.md](CLAUDE.md) and [docs/](docs/): start with
[docs/foundations.md](docs/foundations.md) and [docs/roadmap.md](docs/roadmap.md).

## Packaging

Installers and updates are made with [Conveyor](https://hydraulic.dev) by Hydraulic, free for
open-source projects.
